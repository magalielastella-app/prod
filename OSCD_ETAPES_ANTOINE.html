OSCD Recrutement — Guide d'intégration

Document technique pour Antoine · Branche GitHub : OSCD-devmagalie

Étape 1 — Infrastructure (30 min)

#ActionDétail
1.1Base PostgreSQLCréer une base dédiée (ou réutiliser celle de la solution globale).
1.2Variables d'environnementConfigurer DB_HOST, DB_DATABASE, DB_USERNAME, DB_PASSWORD, APP_KEY, APP_URL, APP_ENV=production
1.3Migrationsphp artisan migrate --force → crée les 11 tables (candidates, cv_documents, cv_analyses, job_offers, interview_reports, interview_scripts, interview_events, recruitment_campaigns, email_templates, sent_emails, job_positions)
1.4Storagephp artisan storage:link → rend le dossier storage/app/cvs/ accessible pour les uploads CV

Étape 2 — Clé API Claude pour l'IA (5 min)

#ActionDétail
2.1Obtenir une cléCréer un compte sur console.anthropic.com → API Keys → Create Key
2.2ConfigurerVariable d'env : ANTHROPIC_API_KEY=sk-ant-api03-...
2.3VérifierSans cette clé, l'app fonctionne mais les 3 fonctions IA (analyse, comparaison, assistant) affichent un message d'erreur.
3 endpoints IA :
• POST /analyses — Analyse individuelle d'un candidat via Claude
• POST /analyses/comparer — Comparaison de 2 à 10 candidats
• POST /candidats/assistant — Bot conversationnel sur le pool de candidats (ex : « qui habite le plus proche de La Tronche ? »)

Étape 3 — Configuration SMTP pour les emails (15 min)

Sans cette étape, le module Emails enregistre l'historique mais les emails ne partent pas réellement.

#ActionDétail
3.1Choisir un fournisseurMailgun (gratuit 100/jour), Resend, SendGrid, ou SMTP de votre messagerie pro
3.2Variables d'envMAIL_MAILER=smtp
MAIL_HOST=smtp.mailgun.org
MAIL_PORT=587
MAIL_USERNAME=...
MAIL_PASSWORD=...
MAIL_FROM_ADDRESS=recrutement@votredomaine.fr
MAIL_FROM_NAME="OSCD Recrutement"
3.3TesterCréer un modèle d'email → envoyer à un candidat test → vérifier réception

Étape 4 — Build & déploiement (10 min)

Option A — Déploiement standalone (Docker)

Le Dockerfile est prêt. Il installe PHP 8.4, Node 22, Composer, build Vite, configure Apache.

docker build -t oscd-recrutement .
docker run -p 8080:8080 \
  -e APP_ENV=production \
  -e DB_CONNECTION=pgsql \
  -e DB_HOST=... \
  -e DB_DATABASE=... \
  -e DB_USERNAME=... \
  -e DB_PASSWORD=... \
  -e ANTHROPIC_API_KEY=sk-ant-... \
  oscd-recrutement

Option B — Intégration dans une app existante

Copier les fichiers listés dans OSCD_RECRUTEMENT_DOCUMENTATION.md (models, controllers, migrations, pages Vue). Points d'attention :

#PointAction
4.1RoutesPréfixer avec /recrutement pour éviter les conflits. Toutes les mutations en POST (jamais PUT/DELETE — bloqués par certains proxies).
4.2AuthRéutiliser le système d'auth existant. Retirer EnsurePasswordChanged de bootstrap/app.php si non souhaité.
4.3NavigationIntégrer les 9 liens dans le menu de la solution globale.
4.4TailwindMerger les couleurs brand-* de tailwind.config.js dans la config globale.
4.5PermissionsAjouter un système de permissions si nécessaire (actuellement tout utilisateur connecté a accès à tout).
4.6Upload CVSi S3, remplacer 'local' par 's3' dans CvDocumentController::store().
4.7Base de donnéesLes 4 migrations tournent sur la même base que l'app globale (noms de tables uniques, pas de conflit).

Cache post-déploiement

php artisan config:cache
php artisan route:cache
php artisan view:cache

Étape 6 — Commandes récap

# Cloner la branche
git clone -b OSCD-devmagalie https://github.com/magalielastella-app/prod.git
cd prod

# Installer les dépendances
composer install
npm install

# Configurer l'environnement
cp .env.example .env
php artisan key:generate
# Éditer .env : DB_*, ANTHROPIC_API_KEY, MAIL_*

# Base de données
php artisan migrate --force
php artisan storage:link

# Build front
npm run build

# Lancer
php artisan serve
# → http://localhost:8000/register
⚠️ Point critique : toutes les mutations HTTP utilisent POST (jamais PUT / DELETE / PATCH). Le proxy de Render (et d'autres reverse proxies) bloque ces verbes. Si Antoine modifie les routes, ne pas introduire de PUT/DELETE sous peine d'erreurs 405 silencieuses.
